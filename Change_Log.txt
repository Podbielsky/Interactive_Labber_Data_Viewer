
changes in v0.4.3:
- implemented new method in HDF5Data for fast data access  of traces via reference
- looking at map with traces does not create a wdir folder with all traces
- saving traces in wdir as numpy arrays is now possible via file menu in the hdf5 overview window
- trace plots under an array are now given a title which specifies their position in the array
- trace plots have now x and y label as class attribute
- included update plot button so colormaps can be changed without resetting further modification (e.g derivatives)
- allow for selected traces to be saved within data menu of the interactive plotter
- included 2d fft on displayed data

changes in v0.4.3a
- included histogram option for time traces
- included polynomial background subtraction
- include median difference background correction

changes in v0.4.4
- bug fix of saving file as .pdf format introducing false raster
- bug fix for coral draw read-in of .pdf files
- removed deprecated histogram map and time trace map plotting as standalone functions from the main .hdf5 file menu
  (functionalities of those functions are taken over by map plot with traces)
- added python file for custom colormaps
- added new cyclic colormap NeonPiCy
- included scaling of displayed data
- aborted measurements can now be displayed
- included background subtraction by relation parameters
- moved derivative and 2d fft to new sub menu called "Tools"
- added tool which allows to draw in arbitrary lines and tells starting and end position


change in v0.4.5
- invert button now also works with update plot
- the start and coordinates of the lines are now rounded to the 6 digit
- added line-wise mean correction
- gradient now uses mean spacing of x and y coordinates do estimate the real gradient and not only the second order difference
- added the possibility to create reduced data sets from the original .hdf5 data
- implemented calculation and plotting of tunnel rates of data, which contains time traces
- implemented creation of compatible .hdf5 files from numpy files containing 2D-arrays
- implemented ROI selection
- implemented BG correction via subtraction of first or last trace
- implemented cutting of data to a certain range via ROI and a new function under Displayed data
- added possibility toggle auto scaling
- bug fix when using ROI and line drawing together
- bug fix lines disapear after updating the plot
- added possibility to modify already drawn lines
- added selective polynomial bg fit

change in v0.4.6
- added mass extraction for .hdf files in a single folder
- removed non used buttons in the main .hdf file
- added linecut extraction
- added fitting of costume defined functions using python syntax including numpy as np and scipy.constants as co
- changed button layout
- added interactive fft-filter

change in v0.4.8
- added an optional, user-configurable measurement database
- added recursive indexing of viewer-compatible HDF5 files with portable
  relative paths and content-based duplicate detection
- added a database browser with directory tree, asynchronous map previews,
  special-measurement stars, and persistent comments
- added automatic, independent database copies for dropped HDF5 files and HDF5
  files created from dropped NPZ archives
- added database rescanning and preservation of comments and stars when a
  uniquely identifiable measurement is moved inside the database
- fixed database previews for measurements declaring more than 32 sweep
  dimensions and prevented large previews from loading complete data channels
- serialized preview I/O, retained only the newest pending selection, reduced
  coordinate reads to their boundary lines, and switched preview rendering to
  an adaptive raster to prevent large files from stalling the browser
- added one-axis measurement recognition based on stored axis channels,
  synthetic Y-axis map display, and linecut database previews
- fixed scalar Step index loading and removed unused full-size parameter-index
  lists that could consume excessive memory for long one-axis measurements
- added Normal and Alternating X-sweep controls to the map viewer, including
  serpentine row correction for coordinates, map data, and trace selection
- fixed grid-orientation detection for alternating coordinate rows so that
  serpentine maps are not incorrectly transposed before row correction
- separated the main map, horizontal crosshair linecut, vertical crosshair
  linecut, and optional time-trace plots into independent canvases
- replaced Matplotlib crosshair artists with lightweight Tk canvas overlays so
  mouse movement no longer redraws the main color map
- retained authoritative calculation arrays as float64 while rendering from
  separate float32 arrays downsampled to the current map-canvas pixel size
- added debounced adaptive resampling after map-window resizing
- fully decoupled cursor motion from linecut rendering by coalescing requests,
  rate-limiting updates, and blitting persistent line artists over cached axes
- coalesced the complete crosshair pipeline so guide movement, cell lookup, and
  linecut updates consume only the newest pointer position at approximately
  30 Hz
- added a default Fast crosshair mode that uses the native system cursor and
  avoids moving guide lines over the large map bitmap
- disabled Matplotlib QuadMesh mouseover hit-testing, which previously scanned
  the pcolormesh during every toolbar motion event on large datasets
- replaced live ROI and new-line Matplotlib redraws with coalesced native canvas
  previews and commit their permanent artists only when selection finishes
- fixed native crosshair and interaction overlays being covered by the TkAgg
  color-map image after a Matplotlib redraw
- moved the Fast crosshair checkbox from the toolbar into the right-side plot
  controls beside the histogram and X-sweep settings
- made non-blitted Matplotlib figure and axes backgrounds transparent and
  matched their Tk canvases and axis details to the active application theme
- added a high-contrast outline to the full crosshair guides and explicitly
  raised them after map redraws and each scheduled cursor update
- prevented persistent/ghost linecuts by using an opaque, theme-matched backing
  for the two TkAgg canvases whose animated artists are updated with blitting
- added persistent plot-style preferences for the preferred map colormap,
  shared crosshair-linecut/histogram color, and extracted-linecut color cycle
- added a reusable Plot Colors dialog to the main Style menu and map plotters,
  including live color-cycle previews and restore-default controls
- added standard Matplotlib colors and palettes together with Viridis, Plasma,
  Inferno, Cividis, BiMap, NeonPiCy, RedMap, and BlueMap-inspired choices
- made colormap changes in the map plotter update the saved default and added a
  live, persistent color-cycle selector to the extracted-linecut plotter
- applied plot-style changes to already-open map, histogram, crosshair-linecut,
  and extracted-linecut artists while retaining safe defaults for older or
  partially edited preferences.json files
- added plot_style.py to both the Windows and macOS/Linux installer manifests
  so fresh installations include the plotting-preference module
- applied the preferred colormap to database-browser map previews and refresh
  an already-open map preview when the global plotting style changes
- added extracted-linecut cycles generated from every installed standard
  ttkbootstrap theme's semantic color palette
